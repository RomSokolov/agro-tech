# AgriField — маркетплейс сельскохозяйственной техники

Коммерческий сайт-каталог для дилера новой и подержанной сельхозтехники
(тракторы, комбайны, опрыскиватели, сеялки, погрузчики и почвообрабатывающее
оборудование). Включает маркетинговую главную страницу, каталог техники с
фильтрами, страницы с подробным описанием и формами захвата лидов, а также
внутренний инбокс лидов.

## Возможности

- **Главная страница** — hero-блок, категории техники, рекомендованные машины,
  блоки преимуществ и процесса работы, с анимациями при скролле.
- **Каталог** — server-rendered листинг с фильтрацией через URL по категории,
  бренду, состоянию, диапазону цен и минимальной мощности, плюс сортировка.
- **Страницы техники** — полные характеристики, ключевые факты и форма «запросить
  предложение», генерируются статически для каждой машины.
- **Захват лидов** — формы запроса предложения и обратной связи с валидацией,
  сохраняются в базу данных через API-роут.
- **Инбокс лидов** — внутренняя страница `/admin/leads` со списком всех заявок.
- **Адаптивный UI** — mobile-first вёрстка с выезжающей панелью фильтров и
  мобильной навигацией.
- **SEO** — метаданные для каждой страницы, Open Graph теги, `sitemap.xml` и
  `robots.txt`.

## Технологический стек

| Область     | Выбор                                              |
| ----------- | -------------------------------------------------- |
| Фреймворк   | Next.js 16 (App Router) + React 19 + TypeScript    |
| Стилизация  | Tailwind CSS v4                                    |
| UI          | Кастомные компоненты на примитивах Radix           |
| Анимация    | Framer Motion                                      |
| Формы       | React Hook Form + валидация Zod                    |
| База данных | Prisma ORM с SQLite (driver adapter)               |

## Начало работы

### Требования

- Node.js 20+
- npm

### Установка

```bash
npm install
```

### Окружение

Скопируйте пример env-файла:

```bash
cp .env.example .env
```

Значение `DATABASE_URL` по умолчанию указывает на локальный SQLite-файл и не
требует изменений для разработки.

### База данных

Примените схему и засидьте каталог тестовой техникой:

```bash
npm run db:migrate
npm run db:seed
```

### Запуск

```bash
npm run dev
```

Сайт доступен по адресу `http://localhost:3000`.

## Структура проекта

```
app/
  catalog/            Листинг каталога и страницы техники
  admin/leads/        Внутренний инбокс лидов
  api/leads/          Эндпоинт отправки лидов
  delivery, service, about

  catalog/            Панель фильтров и тулбар
  equipment/          Карточка техники и сгенерированные визуалы
  forms/              Форма лида
  site/               Хедер, футер, заголовок страницы

lib/                  Доступ к данным, типы, валидация, константы

```

## Примечания

- Изображения техники используют сгенерированные SVG-визуалы, чтобы проект
  запускался без внешних ассетов; реальные фото товаров можно добавить через
  поле `images`.
- `/admin/leads` не защищён авторизацией в демонстрационных целях — в продакшене
  он находился бы за аутентификацией.

## Деплой в продакшен

SQLite используется для локальной разработки. Для хостинг-деплоя (например,
Vercel) переключите datasource на PostgreSQL:

1. Измените провайдер `datasource` в `prisma/schema.prisma` на `postgresql`.
2. Установите `DATABASE_URL` на connection string хостингового Postgres.
3. Замените SQLite driver adapter в `lib/db.ts` на адаптер Postgres.
4. Выполните `npm run db:migrate` для новой базы данных и `npm run db:seed`.
